# App Store 上架清单

按「什么时候能做」分四段。带 ⛔ 的是没它就上不了的硬门槛。

## 一、现在就能做（不需要账号）

- [x] 工程骨架、CI 构建链
- [ ] 应用图标：1024×1024 无圆角无透明通道（Apple 自己加圆角）
- [ ] 启动画面：纯色或极简图形，别放说明文字
- [ ] 隐私政策页面：GitHub Pages 托管一个静态页即可，必须能从公网打开
- [ ] 支持页面：同上，可以就是 README 的网页版
- [ ] 商店文案：中英文名称、副标题（30 字）、描述、关键词（100 字符）
- [ ] 截图：6.9 寸（iPhone 17 Pro Max，1320×2868）至少 3 张，6.5 寸可选

## 二、⛔ 需要先付费注册

**Apple Developer Program（个人 ¥688/年）**

1. 用 Apple ID 登录 developer.apple.com，选 Individual
2. 实名（身份证）+ 双币信用卡；审核通常 1~3 天
3. 开好之后拿到 **Team ID**（10 位），后面 CI 签名要用

**公司主体**额外要 D-U-N-S 编码，免费申请但要 1~2 周。

## 三、⛔ 提交前的技术准备

| 项 | 说明 |
|---|---|
| Bundle ID | `com.<你的域>.modelpaintpal`，在 App Store Connect 注册后不可改 |
| 签名证书 | Apple Distribution + App Store 描述文件；CI 用 `.p12` + base64 存 Secrets |
| 上传凭据 | App Store Connect API Key（`.p8` + Key ID + Issuer ID），比密码稳 |
| Privacy Manifest | `PrivacyInfo.xcprivacy`，声明不追踪、不收集数据、用到的必要 API |
| 相册权限文案 | `NSPhotoLibraryUsageDescription`，中文要写清用途：「选择照片用于取色」 |
| 出口合规 | `ITSAppUsesNonExemptEncryption = NO`，省掉每次提交的加密问卷 |
| 方向锁定 | `UISupportedInterfaceOrientations` 只留竖屏 |

## 四、⛔ 中国区特有问题：App 备案

只要应用**存在联网行为**，在中国区上架就必须有备案号，否则审核会卡。本项目
「联网核实颜料信息」正好踩线。

办理大致路径（各地管局口径略有差异，以接入商要求为准）：

1. 主体 ICP 备案（个人可办，需实名）
2. 一个已实名的域名
3. 中国大陆节点服务器（≥3 个月）
4. 通过云服务商提交 App 备案：名称、包名、功能说明、上线商店
5. 管局终审 7~20 个工作日 → 拿到备案号
6. 回填 App Store Connect，并在应用内「关于」页静态展示

**建议的推进顺序**：先上架海外区（含港澳台），备案并行办；备案下来再开国区。
功能一行都不用改，只是分两次开区域——比等备案下来才能提交要省很多时间。

## 审核容易被打回的几个点

- 4.2 最低功能：工具类要能说清「解决什么问题」，别只有一个取色圆点
- 2.5.2 下载代码：不允许运行时下载并执行代码。我们全部功能内置，没问题
- 隐私标签与实际不符：声称不收集数据，就不能有埋点、统计 SDK
- 截图与实际界面不符：截图必须来自真实运行的应用
